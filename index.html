대표 프로젝트

커머스 상품 상세 페이지 개편 Next.js이미지 최적화 이미지 지연 로딩과 서버 렌더링으로 첫 화면 표시 시간을 4.1초에서 1.8초로 줄였습니다.
병원 진료 예약 화면 React웹 접근성 달력과 시간 선택을 키보드와 화면 낭독기로도 쓸 수 있게 다시 만들었습니다.
사내 디자인 시스템 패키지 StorybookTypeScript 버튼부터 표까지 컴포넌트 42개를 만들고 문서 사이트를 함께 운영합니다.
관리자 대시보드 TanStack Table성능 주문 1만 건 표를 끊김 없이 넘겨 보도록 가상 스크롤을 넣었습니다.

기술 스택

  1. 자주 쓰는 것TypeScript · React · Next.js · TanStack Query
  2. 써 본 것Vue 3 · Svelte · Node.js · GraphQL
  3. 도구Vite · Playwright · Storybook · GitHub Actions

자주 받는 질문

외주 작업도 받으시나요?

주말에 진행할 수 있는 2주 이내 작업만 받고 있습니다. 메일로 일정과 범위를 알려 주세요.

백엔드도 하시나요?

코드를 볼 수 있나요?
